# S-4: Graph stability under implementation change

**SDP §23 criterion**: Replacing a solver, CAD system, optimizer, or
compute backend does not change the Engineering Graph schema,
project structure, or workflow definitions.

## Mechanism

The dark-build CI runs `crates/aether_exec/tests/mvr_04_05_12.rs`
on every commit. The fixture asserts:

1. The same package produces equivalent results across the
   Local, Slurm, Apptainer, SSH-batch, and agent-pool backends.
2. Strict reproducibility produces bit-identical output across
   re-runs.
3. The same package produces equivalent results across `x86_64` and
   `aarch64` (the kernel is arch-neutral).

The fixture dispatches the same plugin to each backend and
asserts that the contract surface is honored uniformly.
