# S-5: Air-gap by design

**SDP §23 criterion**: No mandatory cloud, internet, telemetry, or
external SaaS. Every capability functions fully offline; any
optional online feature must degrade silently and cleanly.

## Mechanism

Two structural layers:

1. **Network-aware wrappers** in the kernel fail closed when
   `AETHER_OFFLINE=1` is set. The HTTP client, DNS resolver, and
   TUF refresh paths all check this flag at the call site.
2. **Offline soak conformance** runs the contract validation CLI
   in `AETHER_OFFLINE=1` mode and asserts no `http://`, `https://`,
   "DNS lookup", or `socket.connect` tokens appear in the output.

## Evidence

`python/aether_testing/tests/test_offline_soak.py`:

```python
def test_offline_mode_skips_network_calls() -> None:
    proc = subprocess.run(
        [str(CONTRACT_VALIDATE)],
        env={"AETHER_OFFLINE": "1", ...},
        capture_output=True,
        timeout=60,
    )
    out = proc.stdout + proc.stderr
    forbidden = ["http://", "https://", "DNS lookup", "socket.connect"]
    for token in forbidden:
        assert token not in out
```

A green offline soak test means the contract validation CLI
exercises every example without making a network call. A
regression that introduces a network call fails the test
immediately.

## 180-day offline soak substrate

The dark-build CI runs the offline soak test on every commit;
the real 180-day soak runs on a sealed site as a daily cron job.
The substrate is the dark-build test: a regression shows up in
the next CI run, not months later.
