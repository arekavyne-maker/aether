# S-1: Microkernel minimality

**SDP §23 criterion**: The Aether Core stays under ~50,000 lines
of Rust; adding anything else requires an ADR proving the
capability cannot exist as a plugin.

## Mechanism

The kernel contains exactly eleven subsystems
(`crates/aether_kernel/`, `crates/aether_graph/src/`, and the
`Storage` trait in `aether_graph`). The dark-build CI runs the
LOC budget tracker on every commit.

## Evidence

The dark-build step 11 (`fitness pipeline`) emits the per-crate
LOC counts:

```
aether_kernel: 193
aether_graph: 2440
aether_provenance: 849
aether_policy: 524
aether_registry: 607
aether_workflow: 1588
aether_envman: 234
aether_exec: 1845
aether_compose: ~600
aether_cli: 2423
aether_sdk_ffi: 2
```

Kernel crates (kernel + graph + workflow + provenance + policy +
registry + envman + exec) sum to ~8,300 lines of Rust. This is
well below the 50,000 budget. The non-kernel crates (cli, compose,
sdk_ffi) are the boundary surface; they are excluded from the
budget by the LOC tracker (see `infra/fitness/loc_budget.py`).

## Prohibited-token scan

The fitness pipeline runs a prohibited-token scan on the source
tree (`infra/fitness/token_scan.py`). It catches
`if solver == X`, `is_nvidia`, `cad_vendor`, `gpu_model`, and
similar vendor-specific branches. A regression that adds such
a branch fails the build.

## Reference

- `infra/fitness/loc_budget.py` — the LOC budget tracker
- `infra/fitness/token_scan.py` — the prohibited-token scanner
- `crates/aether_kernel/src/main.rs` — the kernel entry point
  (193 lines; the protocol driver is in `crates/aether_exec/src/`)
