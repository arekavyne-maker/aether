# Aether 3.0 — Architecture Decision Records

The canonical ADR set lives in [`../../specs/adr/`](../../../specs/adr/).
This directory exists so the Aether 3.0 documentation tree has a stable
`docs/architecture/ADR/` entry point without duplicating records.

New records start at ADR-0025. Each record must state context, decision,
alternatives, and consequences. Accepted records are immutable; changes create
a superseding record.
