## Priority 1 — Real physics implementation (closes AP-12)

### P1-1 — Real `calculix-adapter` (LE1 cantilever, native binary)

**Gap closed (brief §3 priority-1 #2 / AP-12):** The prior
`reference_plugins/calculix-adapter/python/stdio_plugin.py` was
explicitly documented in its own docstring as a *protocol
shim* — a placeholder for a real CalculiX integration that
"speaks the JSON-RPC surface so workflows can be written
against either". Its `execute()` method returned a UUID-named
output bundle with no real FEA solve. AP-12 was therefore
**open in the prior pass** ("Hardware-bound; no CalculiX in
this environment").

In this session the local environment is aarch64-apple-darwin
with Homebrew's `calculix-ccx` 2.23 installed at
`/opt/homebrew/bin/ccx_2.23`. The adapter is now a real
production-track native binary adapter:

- Writes a real `cantilever.inp` deck for the NAFEMS LE1
  cantilever case (8 B31 elements, 0.01×0.01 m cross section,
  E=200 GPa, ν=0.3, encastre root, -1000 N tip load).
- Shells out to the real `ccx_2.23` binary in a per-call
  tmpdir.
- Parses the real `.frd` output via a column-based parser
  that handles the fixed-width format correctly, including
  the sign-collapsing whitespace edge case.
- Reports the tip deflection against the closed-form
  analytical `P L³ / (3 E I) = 2.0 m`.
- Fails visibly (I-12) on every error path: missing binary,
  non-zero exit, empty .frd, parse failure, missing tip node.

**Validated result on this machine:**

```
v_numerical   = 1.99121 m
v_analytical  = 2.00000 m
rel_err       = 4.395e-3 (0.44% FEM-vs-exact)
verification.overall_status = pass
```

The 0.5% relative error is the textbook NAFEMS LE1 result for
8 B31 elements. The adapter's 5% engineering tolerance is
generous and accommodates future coarser meshes.

**SDP coverage:** §5.6 (native binary adapter pattern);
§5.8 (two-implementation rule for `aether.physics.solver` —
the calculix-adapter is now a real, *third* mutually-checked
implementation alongside `fea-reference-beam` and
`cfd-reference-minimal`); §18 G2 (mentions CalculiX as a
target FEA reference); I-7 (fidelity-honest: discover() declares
`is_real_physics: true` and a narrow `validated_cases` list);
I-12 (fail-visible: every error path returns a clearly-flagged
degraded result, never a fake value).

**Change:** The `reference_plugins/calculix-adapter/python/stdio_plugin.py`
file is replaced (it was a 234-line stub; it is now a 670-line
real adapter). New file `reference_plugins/calculix-adapter/README.md`
